# Uno-Desenvolvimento-Web
Trabalho referente a matéria Desenvolvimento Web, do 5 semestre, alunos Edgar Jr. Berlanda e Pedro Lucas Marció.

O trabalho se refere a um sistema baseado em marketplace, voltado a cultura familiar rural e pequenos e médios produtores, os conectando diretamente com seu consumidor final. O projeto vai consistir em um sistema de postagem de anúncios, caixa de mensagens e em certos casos sistema de pagamentos, para checkout de compras dentro do aplicativo.

## Algumas funcionalidades
*   **Autenticação de Usuários:** Cadastro, login e controle de sessão segura.
*   **Gestão de Anúncios:** Criação e visualização de anúncios.
*   **Sistema de Pedidos:** Realização e acompanhamento de pedidos no marketplace.
*   **Notificações em Tempo Real:** Alertas para usuários sobre novos eventos.
*   **Upload de Imagens:** Suporte para envio de fotos.

## Instruções para execução
1. Extraia o arquivo
2. Abra o compilador e acesse o local o arquivo pelo terminal
3. Na parte de banco não precisa conectar, pois as credencias para conexão do
banco já estão no arquivo chave.json
4. Rode um npm install no terminal para instalar as dependencias
5. Para iniciar o servidor: npx nodemon index.js ou nodemon index.js ou node
index.js (como preferir)
6. Acesse com: http://localhost:5000
